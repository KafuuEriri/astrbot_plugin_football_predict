# AstrBot 体彩世界杯模拟投注插件

中文 | [English](README_EN.md)

## 简介

这是一个 AstrBot 插件，用于在群聊中模拟体彩足球世界杯投注。插件会定期通过彩票接口获取足球赛事和赔率，将数据缓存到本地 CSV 文件；群成员通过每日签到领取虚拟币，并基于缓存赛事进行模拟下注。

> 本插件仅用于娱乐和学习，不涉及真实金钱交易。

## 功能

- 定期抓取足球赛事和赔率
- 本地 CSV 缓存，普通用户命令不实时请求接口
- 群成员每日签到领取 20000 虚拟币
- 支持主胜、平、客胜模拟投注
- 下注时锁定当前缓存赔率
- 支持撤单、投注记录、账户查询和群内排行
- 支持管理员刷新赛事、录入赛果和手动结算
- 核心逻辑配套单元测试

## 安装

1. 将插件目录放入 AstrBot 插件目录。
2. 安装依赖：

```bash
pip install -r requirements.txt
```

3. 在 AstrBot 中启用插件。

## 配置

插件配置见 `_conf_schema.json`。常用配置：

| 配置 | 默认值 | 说明 |
| --- | ---: | --- |
| `fetch_interval_minutes` | `180` | 彩票接口抓取间隔，单位分钟；默认 3 小时，避免频繁访问接口 |
| `settlement_interval_minutes` | `10` | 结算扫描间隔，单位分钟 |
| `days_ahead` | `7` | 缓存未来多少天赛事 |
| `daily_checkin_amount` | `20000` | 每日签到金额 |
| `initial_balance` | `0` | 新账户初始余额 |
| `min_bet_amount` | `100` | 单笔最小投注金额 |
| `max_bet_amount` | `100000` | 单笔最大投注金额 |
| `bet_close_minutes_before_match` | `5` | 开赛前多少分钟停止投注和撤单 |
| `competition_keywords` | `世界杯,World Cup` | 赛事过滤关键词，逗号分隔 |
| `auto_fetch_on_start` | `true` | 插件启动时是否自动刷新一次缓存 |

## 用户命令

| 命令 | 说明 |
| --- | --- |
| `/足球帮助` | 查看帮助 |
| `/足球签到` | 每日签到领取虚拟币 |
| `/足球账户` | 查看账户余额和投注统计 |
| `/世界杯赛事 [页码]` | 查看缓存中的可投注世界杯赛事 |
| `/足球赔率 <场次编号或match_id>` | 查看单场赔率详情 |
| `/足球投注 <场次编号或match_id> <主胜|平|客胜> <金额>` | 模拟下注 |
| `/足球撤单 <投注单号>` | 停售前撤单 |
| `/我的投注 [未结|已结|页码]` | 查看投注记录 |
| `/足球排行` | 查看当前群排行榜 |

示例：

```text
/足球签到
/世界杯赛事
/足球赔率 周五003
/足球投注 周五003 主胜 1000
/我的投注 未结
/足球排行
```

## 数据存储

插件运行数据保存在 AstrBot 数据目录中：

```python
StarTools.get_data_dir("astrbot_plugin_football_predict")
```

主要文件：

| 文件 | 说明 |
| --- | --- |
| `matches.csv` | 最新赛事和赔率缓存 |
| `odds_history.csv` | 赔率快照历史 |
| `users.json` | 用户账户 |
| `bets.json` | 投注订单 |
| `transactions.csv` | 余额流水 |
| `manual_results.csv` | 管理员手动录入赛果 |
| `fetch_state.json` | 最近一次抓取状态 |

python3 -m compileall .

## 注意事项

- 普通用户命令只读取本地缓存，不会实时请求彩票接口。
- 彩票接口可能不稳定提供最终赛果，因此保留管理员手动录入赛果功能。
- 投注为虚拟模拟，不代表真实体彩投注结果。
- 请合理设置抓取间隔，避免频繁访问接口。
